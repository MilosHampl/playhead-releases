# Playhead — downloads and issues

Playhead streams a torrent's video while it downloads and plays it in a native macOS player.
This repository holds the **downloads**, the **website** and the **issue tracker**; the source code is private.

- **Download**: [latest macOS build](https://github.com/MilosHampl/playhead-releases/releases/latest) (macOS 12+, Apple Silicon and Intel)
- **Website and docs**: https://miloshampl.github.io/playhead-releases/
- **Report a problem or suggest something**: [open an issue](https://github.com/MilosHampl/playhead-releases/issues/new/choose)

First launch: test builds aren't notarized, so open **System Settings → Privacy & Security → Open Anyway** once.
Details in the [docs](https://miloshampl.github.io/playhead-releases/docs.html#first-launch).

This product uses the TMDB API but is not endorsed or certified by TMDB.
